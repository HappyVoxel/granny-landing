# granny-landing

The landing page for [granny](https://github.com/HappyVoxel/granny), a strict
macOS task enforcer. Next.js static export, leather-and-brass.

Live at <https://granny.happyvoxel.com>.

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm build        # static export to out/
pnpm typecheck
pnpm lint
```

Deployment (Docker + Woodpecker + Easypanel): [docs/deployment.md](docs/deployment.md).
